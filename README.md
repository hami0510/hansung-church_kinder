공지 · 일정 · 주일 출석부 · 심방/기도제목 요청 · 섬김 배정을 한 곳에서 관리합니다.

🔗 https://hsc-kinder.streamlit.app

## 🏠 홈

- 공지 3건 (📌 고정 1건 + 최신 2건), 누르면 그 자리에서 펼쳐집니다
- 월간 달력 (공휴일 자동 표시), 일정을 누르면 팝업
- 모든 날짜는 **한국 시간** 기준입니다

## 📌 사이드메뉴 하단 카드

- **🙏 이번 주 섬김**: 이번 주일의 1부·2부 헌금기도 / 대표기도 / 청소당번
  - 월요일부터 다음 주일 내용으로 자동 전환
  - 미입력이면 "미배정"
- **📖 이번 주 암송구절**: 주 1회 자동 변경 (목록은 `utils/verses.py`)

## 📢 공지사항

- 누구나 보기 · 검색 가능
- 작성 / 수정 / 삭제 / 📌 고정은 **관리자만**

## 📅 일정 관리

- 날짜 띠 + 한 줄 일정, 줄을 누르면 수정창
- 구분 색 점: 🔵 심방 · 🟡 예배 · 🟢 행사 · 🟣 교사회의 · 🟠 교육 · ⚪ 기타
- 이번 주 일정은 바로 보이고, 이후 일정은 접혀 있음
- 일정 보기 · 등록 · 수정 · 일괄 삭제

## 📋 주일 출석부

출결은 **두 단계**로 운영합니다.

| 단계 | 시기 | 입력 |
|---|---|---|
| 📝 예정 (주중) | 월~토 | **선생님 누구나** (토 12시까지) |
| ✅ 실제 (주일) | 일요일 | **관리자(총무)** |

- 접속 요일에 따라 단계가 자동 선택 (월~토 예정 / 일요일 실제)
- **1부 / 2부** 선택, 주일 날짜는 월요일이 되면 다음 주일로 자동 전환
- 지난 주 기록은 날짜를 바꿔서 확인

### 📝 예정 (주중)
- 이름을 누르면 **예정 / 불참(+사유) / 미정** 입력
- 비밀번호 없이 입력 가능, 팝업에 **마지막 수정 시각·입력자(선택)** 표시
- 토요일 12시 이후는 선생님 입력 차단 (관리자는 수정 가능)
- 상단 카드: 학생 예정 · 교사 예정 · 미정/미입력 · 불참
- 불참 예정은 **접어 둔 목록**(반별 묶음)으로 표시
- **📋 반별 예정 요약**: 카톡에 바로 복사해 올릴 글

### ✅ 실제 (주일)
- 이름을 누르면 **출석 / 결석(+사유)**, 잘못 눌렀다면 기록 지우기
- 상단 카드: 학생 출석 · 출석률 · 교사 출석 · 전체 출석
- **📊 예정 vs 실제** 비교, 예정했으나 결석·미확인 인원 표시
- 결석 목록은 접어 둔 목록(반별 묶음)
- **🌟 새신자 추가**(관리자): 이름만 입력하면 새싹반에 추가되고 그 주일 출석 처리

### 표 색상
- ✓ 출석 · ○ 예정(초록) / ✕ 결석·불참(빨강) / ? 미정(노랑) / 흰색 미확인

### 결석 · 불참 사유
연락안됨 · 병결(본인 혹은 가족) · 출근, 출장 · 가족모임(명절, 여행 등) · 경조사(장례식, 결혼식) · 이사 · 외국 · 출산 · 타교회 · 1회성 · 기타 개인사정 · 대예배

### 📱 휴대폰에서
- **모바일 보기 스위치를 켜 주세요** (이름 5칸씩 크게 표시)

### ✏️ 명단 관리 (관리자)
- 반별 담임샘 / 학생 이름 입력 (쉼표 또는 줄바꿈), 저장 시 **가나다순 자동 정렬**
- 저장 후 다음 반으로 이어서 등록
- ⚠️ 이름을 지우면 그 이름의 출결·예정 기록도 삭제됩니다
- 동명이인은 `김하온A`처럼 구분

## 🙏 섬김 배정 (관리자)

- 메뉴 **섬김 배정**: 주일 날짜 + 1부/2부별로 헌금기도 · 대표기도 · 청소당번(쉼표로 여러 명) 입력
- 저장하면 입력칸이 비워지고, **최근 배정 표의 행을 누르면 수정·삭제 팝업**
- 사이드메뉴 카드에 이번 주 배정이 바로 반영

## 🏠 심방 요청

- 선생님 이름 + **숫자 4자리 비밀번호**로 요청
- 이름 + 비밀번호로 **내 요청 수정·삭제** ('접수' 상태일 때만)
- 목록 · 처리 상태 변경은 **관리자**

## 🙏 기도제목 요청

- 올리기 · 내 기도제목 수정·삭제는 심방 요청과 동일 (4자리 비밀번호)
- **목록 열람 · 상태 변경(기도중/응답) · 삭제는 목사님만**
  - **🔒 목사님 확인** 탭에서 목사님 전용 비밀번호 입력
  - 관리자(총무)도 목록을 볼 수 없음

## 🛡️ 개인정보 원칙

- 저장: **이름 · 반 · 출결(예정) · 결석 사유 · 섬김 배정**만
- 전화번호 · 주소 · 생년월일 · 사진은 받지 않음

- 저장소가 Public이므로 이름 명단과 키 값을 코드에 넣지 않기
- 화면 제한은 앱 기준입니다. Supabase 접근 권한이 있는 사람은 DB에서 내용을 볼 수 있습니다

## 🧰 개발자 메모

### 구성
Streamlit · Supabase · GitHub · Streamlit Cloud

### 폴더
```
app.py              메뉴 · 관리자 로그인 · 사이드바 카드
requirements.txt
logo.png
utils/
  auth.py           권한
  db.py             DB 읽기/쓰기
  ui.py             공통 CSS · 배너
  passcode.py       요청용 4자리 비밀번호
  verses.py         암송구절 목록
  notify.py         알림 자리 (미연결)
views/
  home.py           홈
  notices.py        공지사항
  events.py         일정 관리
  roster_grid.py    주일 출석부 (예정/실제)
  duties.py         섬김 배정
  visit_request.py  심방 요청
  prayer_request.py 기도제목 요청
```

### Supabase 테이블
- `events` 일정 · `notices` 공지
- `visit_requests` 심방 요청 · `prayer_requests` 기도제목 요청
- `roster_members` 학생·담임·스탭 · `roster_classes` 반별 담임 표시
- `roster_attendance` 날짜별 실제 출결 · `roster_plan` 날짜별 주중 예정
- `duties_weekly` 주별 섬김 배정
- `roster_visitors` 방문자 수 (현재 미사용)

### Secrets
Streamlit Cloud → Manage app → Settings → Secrets (**GitHub에는 올리지 않기**)

```toml
[supabase]
url = "https://<프로젝트>.supabase.co"
key = "sb_secret_..."

[auth]
admin_password = "관리자 비밀번호"
pastor_password = "목사님 전용 비밀번호"
```

### 수정 · 배포
1. GitHub에서 파일 Edit → 붙여넣기 → Commit changes
2. 1~2분 뒤 자동 반영, 안 바뀌면 Manage app → ⋮ → **Reboot app**
3. 오류는 Manage app 로그 맨 아래 줄 확인
4. 서버 시간은 UTC이므로 날짜 계산은 `datetime.now(ZoneInfo("Asia/Seoul"))`를 사용

주요 패키지: `streamlit>=1.40` · `supabase` · `pandas` · `streamlit-calendar` · `holidays` · `streamlit-aggrid`

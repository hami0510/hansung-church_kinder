교사진을 위한 웹 앱입니다.
공지 · 일정 · 주일 출석부 · 심방/기도제목 요청을 한 곳에서 관리합니다.

🔗 https://hansung-churchkinder.streamlit.app

> 📱 휴대폰은 **사파리(아이폰) / 크롬(안드로이드)** 로 열어 주세요.
> 카톡 링크는 "다른 브라우저로 열기"를 권장합니다.

## 🏠 홈

- 공지 3건 (📌 고정 1건 + 최신 2건)
- 공지를 누르면 그 자리에서 펼쳐집니다
- 월간 달력 (공휴일 자동 표시)
- 일정을 누르면 팝업으로 열립니다

## 📢 공지사항

- 누구나 보기 · 검색 가능
- 작성 / 수정 / 삭제 / 📌 고정은 **관리자만**
- 삭제는 동의 체크 후 진행

## 📅 일정 관리

- 일정 보기 · 등록 · 수정 · 일괄 삭제
- 구분: 예배 / 행사 / 교사회의 / 교육 / 심방 / 기타

## 📋 주일 출석부

출결은 **두 단계**로 운영합니다.

| 단계 | 시기 | 용도 |
|---|---|---|
| 📝 예정 (주중) | 월~토 | 반별 참석 예정 파악 |
| ✅ 실제 (주일) | 일요일 | 당일 실제 출석 |

- 접속 요일에 따라 **처음 열리는 단계가 자동 선택**됩니다
  - 월~토 → 📝 예정 / 일요일 → ✅ 실제
- 단계는 상단 버튼으로 직접 바꿀 수 있습니다
- **1부 / 2부** 선택, 주일 날짜는 월요일이 되면 다음 주일로 자동 전환
- 지난 주 기록은 날짜를 바꿔서 확인

### 📝 예정 (주중)
- 이름을 누르면 **예정 / 불참(+사유) / 미정** 입력
- 표 색: ○ 예정(연초록) · ✕ 불참(연빨강) · ? 미정(노랑)
- 마감: 토요일 12시 이후 "마감" 안내 (관리자는 이후에도 수정 가능)
- 상단 카드: 학생 예정 · 교사 예정 · 미정/미입력 · 불참
- **📋 반별 예정 요약**: 카톡에 바로 복사해서 올릴 수 있는 글

### ✅ 실제 (주일)
- 이름을 누르면 **출석 / 결석(+사유)** 입력, 잘못 눌렀다면 **기록 지우기**
- 표 색: ✓ 출석(초록) · ✕ 결석(빨강) · 미확인(흰색)
- 상단 카드: 학생 출석 · 출석률 · 교사 출석 · 전체 출석
- **📊 예정 vs 실제** 비교 (예: 예정 72 → 실제 68, -4)
- 예정했으나 결석 / 아직 미확인 인원 표시
- 결석자는 표 아래에 사유와 함께 요약

### 결석 · 불참 사유
연락안됨 · 병결(본인 혹은 가족) · 출근, 출장 · 가족모임(명절, 여행 등) · 경조사(장례식, 결혼식) · 이사 · 외국 · 출산 · 타교회 · 1회성 · 기타 개인사정 · 대예배

### 📱 휴대폰에서
- **모바일 보기 스위치를 켜 주세요**
- 이름이 5칸씩 보여 읽기 쉽습니다

### 🌟 새신자 추가 (관리자, 실제 단계)
- 이름만 입력하면 **새싹반**에 추가
- 그 주일 출석으로 자동 기록

### ✏️ 명단 관리 (관리자)
- 반 선택 → 담임샘 / 학생 이름 입력
- 쉼표 또는 줄바꿈으로 구분
- 저장하면 **가나다순으로 자동 정렬**
- **저장 후 다음 반**으로 이어서 등록
- 동명이인은 `김하온A`처럼 구분
- ⚠️ 이름을 지우면 그 이름의 **출결 · 예정 기록도 삭제**됩니다
- 담임 변경도 여기서 수정

### 권한
- 표 열람: 누구나
- 예정 · 출결 입력, 명단 관리, 새신자 추가: **관리자(총무)만**

## 🙏 심방 요청 · 기도제목 요청

- 선생님 이름 입력 + **숫자 4자리 비밀번호** 설정
- 이름 + 비밀번호로 **내 요청 수정 · 삭제**
- 상태가 **'접수'일 때만** 수정 가능 (처리가 시작되면 잠김)
- 목록 · 처리 상태 변경은 **관리자만**
- 비밀번호를 잊으면 관리자가 대신 처리

- 저장: **이름 · 반 · 출결(예정) · 결석 사유**만

## 🧰 개발자 메모

### 구성
Streamlit · Supabase · GitHub · Streamlit Cloud

### 폴더
```
app.py            메뉴 · 관리자 로그인
requirements.txt
logo.png
utils/
  auth.py         권한
  db.py           DB 읽기/쓰기
  ui.py           공통 CSS · 배너
  passcode.py     요청용 4자리 비밀번호
  notify.py       알림 자리 (미연결)
views/
  home.py         홈
  notices.py      공지사항
  events.py       일정 관리
  roster_grid.py  주일 출석부 (예정/실제)
  visit_request.py   심방 요청
  prayer_request.py  기도제목 요청
```

### Supabase 테이블
- `events` 일정
- `notices` 공지
- `visit_requests` 심방 요청
- `prayer_requests` 기도제목 요청
- `roster_members` 학생 · 담임 · 스탭
- `roster_classes` 반별 담임 표시
- `roster_attendance` 날짜별 실제 출결
- `roster_plan` 날짜별 주중 예정
- `roster_visitors` 방문자 수 (현재 미사용)

### Secrets
Streamlit Cloud → Manage app → Settings → Secrets (**GitHub에는 올리지 않기**)

```toml
[supabase]
url = "https://<프로젝트>.supabase.co"
key = "sb_secret_..."

[auth]
admin_password = "관리자 비밀번호"
```

### 수정 · 배포
1. GitHub에서 파일 Edit → 붙여넣기 → Commit changes
2. 1~2분 뒤 자동 반영
3. 안 바뀌면 Manage app → ⋮ → **Reboot app**
4. 오류는 Manage app 로그 맨 아래 줄 확인

주요 패키지: `streamlit>=1.40` · `supabase` · `pandas` · `streamlit-calendar` · `holidays` · `streamlit-aggrid`

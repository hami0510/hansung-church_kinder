# 한성교회 유치부 관리 시스템

한성교회 유치부 교사진을 위한 웹 앱입니다. 공지, 일정, 주일 출석부, 심방·기도제목 요청을 한 곳에서 관리합니다.

- 앱 주소: https://hansung-churchkinder.streamlit.app
- 구성: Streamlit + Supabase + GitHub + Streamlit Community Cloud

---

## 주요 기능

### 🏠 홈
- 공지 3건 요약 (상단 고정 1건 + 최신 2건), 누르면 그 자리에서 내용이 펼쳐짐
- 월간 달력 (한국 공휴일·대체공휴일 자동 표시)
- 달력의 일정을 누르면 해당 날짜 일정이 팝업으로 열림

### 📢 공지사항
- 누구나 열람, 제목·내용 검색
- 작성·수정·삭제·상단 고정은 **관리자 로그인 후**에만 가능
- 삭제 시 동의 체크 후 진행

### 📅 일정 관리
- 일정 보기 / 등록 / 수정 / 일괄 삭제
- 시간 지정 여부 선택, 구분(예배·행사·교사회의·교육·심방·기타)

### 📋 주일 출석부
- **1부 / 2부** 전환, 주일 날짜 선택 (기본값은 다가오는 일요일, 월요일부터 다음 주일로 자동 전환)
- 조이(5세) / 해피(6세) / 홀리(7세) 색 구분 표, 반별 재적·출석·소계, 새싹반, 교사(담임·스탭) 합계
- 상단 요약 카드: 학생 출석, 출석률, 교사 출석, 전체 출석
- **이름을 누르면 출결 팝업** (출석 / 결석 + 결석 사유 선택 / 기록 지우기) — 학생·담임·스탭 동일
- 출석은 초록(✓), 결석은 빨강(✕), 미확인은 흰색으로 표시, 결석자는 표 아래에 사유와 함께 요약
- 결석 사유: 연락안됨 / 병결(본인 혹은 가족) / 출근, 출장 / 가족모임(명절, 여행 등) / 경조사(장례식, 결혼식) / 이사 / 외국 / 출산 / 타교회 / 1회성 / 기타 개인사정 / 대예배
- **📱 모바일 보기** 스위치: 이름 5칸 구성으로 휴대폰에서도 이름이 읽히도록 표시
- **🌟 새신자 추가**: 이름만 입력하면 새싹반에 추가되고 해당 주일 출석으로 기록
- **명단 관리**: 반별 담임샘·학생 이름 입력 (쉼표 또는 줄바꿈), 저장 후 다음 반으로 이어서 등록
- 날짜별로 출결이 따로 저장되어 지난 주 기록은 날짜를 바꿔 다시 볼 수 있음
- 열람은 누구나, 출결 처리·명단 관리·새신자 추가는 **관리자만** 가능

### 🏠 심방 요청 / 🙏 기도제목 요청
- 선생님 이름을 직접 입력하고, **요청할 때 정한 숫자 4자리 비밀번호**로 본인 요청을 수정·삭제
- '접수' 상태일 때만 작성자가 수정·삭제 가능 (교역자가 처리 상태를 바꾸면 잠김)
- 요청 목록과 처리 상태 변경은 관리자 전용
- 비밀번호는 해시로 저장되며, 잊으면 관리자가 대신 처리

## 권한

| 구분 | 할 수 있는 일 |
|---|---|
| 일반 | 홈, 공지·일정·출석부 열람, 심방·기도제목 요청 작성 및 본인 요청 수정·삭제 |
| 관리자 | 공지 작성·수정·삭제, 일정 관리, 출결 처리, 명단 관리, 새신자 추가, 요청 목록 관리 |

관리자 로그인은 왼쪽 메뉴(휴대폰은 왼쪽 위 `≫`) 아래 **🔒 관리자 로그인**에서 합니다. 5회 틀리면 새로고침 전까지 잠깁니다.

```
  home.py               # 공지 요약 + 월간 달력
  notices.py            # 공지사항
  events.py             # 일정 관리
  roster_grid.py        # 주일 출석부

```

## Supabase 테이블

| 테이블 | 용도 |
|---|---|
| `events` | 일정 |
| `notices` | 공지 (`pinned` 상단 고정) |
| `visit_requests` | 심방 요청 (`pass_hash`) |
| `prayer_requests` | 기도제목 요청 (`pass_hash`) |
| `roster_members` | 학생·담임·스탭 명단 (부, 구분, 반, 이름, 순서) |
| `roster_classes` | 반별 담임샘 표시 텍스트 |
| `roster_attendance` | 날짜별 출결 (`present`, `reason`) |
| `roster_visitors` | 방문자 수 (현재 화면에서는 사용 안 함) |

## 설정 (Streamlit Secrets)

Streamlit Cloud → Manage app → Settings → Secrets에 입력합니다. **GitHub에는 올리지 않습니다.**

```toml
[supabase]
url = "https://<프로젝트>.supabase.co"
key = "sb_secret_..."

[auth]
admin_password = "관리자 비밀번호"
```

## 배포·수정 방법

1. GitHub에서 파일을 Edit → 붙여넣기 → Commit changes
2. 1~2분 뒤 자동 반영 (안 바뀌면 Manage app → ⋮ → Reboot app)
3. 오류 시 Manage app 로그 맨 아래 줄을 확인

`requirements.txt` 주요 패키지: `streamlit>=1.40`, `supabase`, `pandas`, `streamlit-calendar`, `holidays`, `streamlit-aggrid`

## 개인정보 원칙

- 저장하는 정보는 **이름, 반, 출결, 결석 사유**뿐입니다.
- 전화번호·주소·생년월일·사진은 받지 않습니다.
- 심방·기도제목 요청에는 아이 실명이나 가정 사정을 자세히 적지 않도록 안내합니다.
- 앱 주소는 교사진에게만 공유하고, 관리자 비밀번호는 정기적으로 바꿉니다.
- 저장소가 Public이므로 이름 명단이나 키 값을 코드·README에 넣지 않습니다.

## 알려진 한계·향후 계획

- 출석부 표는 휴대폰 화면 폭 때문에 **모바일 보기**를 켜야 이름이 읽힙니다.
- 브라우저·기기에 따라 글꼴과 표 높이가 조금 다를 수 있습니다 (사파리·크롬 권장).
- 출석 통계(월별·개인별), 텔레그램 알림은 아직 없습니다.
- 명단 관리에서 이름을 지우면 해당 이름의 과거 출결 기록도 함께 지워집니다.
- 담임이 바뀌면 출석부의 **명단 관리**에서 담임샘 칸을 수정합니다.
